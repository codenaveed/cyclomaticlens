# Changelog

All notable changes to the Cyclomatic Lens extension will be documented in this file.

## [1.0.0] - Initial Public Release

### Added
- **Multi-language support**: C, C++, Java, JavaScript
- **Inline complexity display**: Shows scores next to each function
- **Color coding**: Visual feedback based on complexity level
- **Real-time analysis**: Updates as you type with debouncing
- **Configuration**: Customizable complexity threshold
- **Comprehensive testing**: Test suite with example files for each language

### Features
- **C/C++ parsing**: Handles function definitions and control structures
- **Java method analysis**: Supports class methods and constructors
- **JavaScript function detection**: Identifies function declarations
- **Threshold warnings**: Visual alerts for complex code
